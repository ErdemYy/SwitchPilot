# Playwright E2E & Visual Testing Guide

## 1. Playwright Setup & Projects
- `chromium-desktop`: 1440x900 viewport testing NOC Dashboard, Topology Viewer, Workflow Builder.
- `webkit-desktop`: macOS Safari viewport validation.
- `responsive-mobile`: Mobile view testing for NOC monitoring alerts.

## 2. Running Playwright
```bash
pnpm --filter @switchpilot/tests test:e2e
```
