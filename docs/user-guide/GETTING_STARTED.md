# SwitchPilot User Getting Started Guide

## 1. Quick Start
1. Log in to SwitchPilot web console or open SwitchPilot Desktop application.
2. Register your network devices under **Device Inventory**.
3. Create neutral **Canonical Configuration Models (CCM)** for VLANs or interfaces.
4. Execute dry-run preview and deploy configurations safely across multi-vendor devices.
